# 공모전 시연 개인정보 운영 기준

이번 기준은 사용자가 요청한 공모전 시연용 보관 정책이다. 타사 정책의 법정 보관 연수를 복사한 것이 아니다.

## 보관 기준

- 회원 정보와 연결된 스탬프 기록: 회원 탈퇴 또는 시연 서비스 운영 종료 중 먼저 도래하는 시점까지.
- 문의 이메일·유형·제목·내용·접수 시각: 문의 처리 완료 시까지.
- 별도 법령에 따른 보존이 실제로 필요한 경우: 적용 근거와 항목, 기간을 확인하여 분리 보관한다. 모든 데이터에 일괄적으로 3년 또는 5년을 적용하지 않는다.

## 현재 구현과 수동 처리

자동 탈퇴·기간 만료 삭제 기능을 이번 변경에서 추가하지 않았다. 아래 절차는 운영자가 수행해야 한다. 화면 문구 변경만으로 데이터가 삭제되지 않는다.

1. 문의 메일 관리자가 탈퇴·삭제 요청을 접수한다. 입력된 회신 이메일만으로 본인이라고 판단하지 않고 계정 소유 여부를 확인한다. 비밀번호·인증번호를 메일로 받지 않는다.
2. DB 관리자는 확인된 회원 식별자로 연결 테이블과 외래 키를 검토한 뒤 해당 회원 정보와 스탬프 등 연결 기록을 삭제한다. 실제 스키마 확인 없이 공용 DB 전체를 초기화하지 않는다.
3. 문의 답변과 필요한 후속 처리가 완료되면 메일 관리자가 수신·발신·전달 사본과 휴지통의 해당 메일을 삭제한다. 문의를 별도 문서로 내려받았다면 그 사본도 삭제한다.
4. 시연 서비스 운영을 종료하면 신규 개인정보 수집을 중단하고 시연용 회원·연결 기록을 삭제한다. 공모전 일정 종료와 서비스 운영 종료를 혼동하지 않는다.
5. DB 백업·내보낸 파일에 개인정보가 남는지도 확인하여 같은 기준으로 처리한다. 외부 저장소의 삭제 제한이나 보존 의무가 있다면 공개 문구도 실제 기준에 맞춘다.
6. 처리 일시와 완료 여부만 최소한으로 기록하고, 삭제한 개인정보를 처리 기록에 다시 복사하지 않는다.

메일 담당자와 DB 담당자가 각각 위 절차를 맡아야 한다. 실제 개인정보를 받는 시연에도 이 기준을 적용한다.
