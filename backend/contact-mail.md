# 문의 메일 설정

문의 폼은 POST /api/contact로 JSON을 보내며, 서버가 기존 JavaMailSender로 관리자에게 텍스트 메일을 전송합니다.
브라우저는 수신자를 지정하지 못합니다. 발신자는 발송 계정이며 회신 주소(Reply-To)는 문의자가 입력한 이메일입니다.

backend/.env 또는 서버 환경변수에 다음을 설정하세요. 실제 값은 커밋하지 않습니다.

- MAIL_USERNAME: Gmail 발송 계정
- MAIL_APP_PASSWORD: 해당 계정의 앱 비밀번호
- CONTACT_RECIPIENT: 문의를 받을 관리자 이메일 (미설정 시 MAIL_USERNAME 사용)

설정 변경 후 백엔드를 재시작합니다. SMTP 서버가 발송을 수락해야 204를 반환합니다. 수신함 도착은 별도로 확인해야 합니다.
발송 오류는 502, 발신/수신 주소 누락은 503, 입력 오류는 400, 연속 발송 제한은 429입니다.
발송 제한은 서버 인스턴스별로 회신 이메일 주소당 1분에 1회, 전체 1분에 30회입니다.
이메일은 공백을 제거하고 대소문자를 구분하지 않아 같은 주소로 제한을 우회할 수 없습니다. 프록시 접속 IP와 전달 헤더는 제한 기준으로 사용하지 않습니다.
회신 이메일은 본인 확인된 신원이 아니므로 이메일 변경에 대비한 전체 발송 제한을 유지합니다. 여러 인스턴스의 통합 제한은 포함하지 않습니다.
서버는 문의 내용을 별도 DB에 저장하지 않습니다. 문의 메일은 문의 처리 완료 시까지 보관하고 운영자가 삭제합니다. 수신함뿐 아니라 답장·전달 사본과 휴지통도 확인합니다. 자동 삭제 기능은 없으며 상세 절차는 privacy-operations.md를 따릅니다.

테스트는 JavaMailSender를 대체하여 수신자 고정, 회신 주소, 입력 검증, SMTP 실패, 연속 발송 제한을 검증합니다.
